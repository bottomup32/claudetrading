# 삼국어 번역기 사용 가이드

한국어를 입력(또는 말하기)하면 중국어(간체)·영어·일본어가 한 번에 나옵니다.

## A. 안드로이드 폰에서 쓰기 (권장, API 키 불필요)

앱 주소: https://claude.ai/artifact/1i5NXCx2oBmp117KptMZMy

1. 폰의 Chrome(또는 Claude 앱)에서 위 주소를 엽니다. claude.ai에 로그인되어 있어야 합니다.
2. 상단 상태가 **준비됨**이면 사용 가능합니다.
3. 입력 방법
   - 텍스트: 입력창에 한국어를 쓰고 **번역**.
   - 음성: **🎤 말하기**를 누르고 한국어로 말합니다. 말이 끝나면 자동으로 번역됩니다
     ("말한 뒤 자동 번역" 체크 해제 시 수동으로 번역 버튼).
4. 첫 번역 때 "이 페이지가 Claude를 사용하도록 허용할까요?" 창이 뜹니다. **허용**을 누릅니다.
5. 결과 카드마다 **듣기**(음성 읽기), **복사**, **공유**(안드로이드 공유 시트) 버튼이 있습니다.
6. 최근 번역 20개는 이 폰 브라우저에만 저장됩니다.
7. 앱처럼 쓰려면 Chrome 메뉴(⋮) → **홈 화면에 추가**.

옵션
- **정확 모드**: 더 좋은 모델을 씁니다. 5초~수십 초 걸릴 수 있습니다. 기본(빠른 모드)은 보통 1~3초입니다.
- 번역은 페이지를 연 사람의 Claude 구독 사용량을 씁니다. 링크를 남에게 공유하면 그 사람의 계정으로 실행됩니다.

문제가 있을 때
- "사용 불가 (claude.ai에서 열어 주세요)": claude.ai 밖에서 열었거나 로그인이 안 된 상태입니다.
- "허용되지 않았습니다": 허용 창에서 거절한 경우입니다. 페이지를 새로고침하면 다시 물어봅니다.
- 마이크 버튼이 안 보임: 그 브라우저가 음성 인식을 지원하지 않습니다. 안드로이드 Chrome을 쓰세요.

## B. PC에서 Flask 웹앱으로 쓰기

```bash
pip install -r translator/requirements.txt
python -m translator.app            # http://localhost:5000
```

- `ANTHROPIC_API_KEY`가 있으면 Claude로, 없으면 무료 백엔드(구글 번역 비공식 엔드포인트)로 번역합니다.
- 같은 와이파이의 폰에서 `http://<PC IP>:5000`으로 접속하면 폰에서도 쓸 수 있습니다.
- 무료 백엔드는 비공식이라 품질이 낮고 예고 없이 막힐 수 있습니다.
